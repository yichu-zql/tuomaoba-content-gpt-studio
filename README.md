目标仓库：https://github.com/yichu-zql/tuomaoba-content-gpt-studio

数据存在当前浏览器，新版使用独立命名空间。文字备份不含门店照片和对标截图。旧版文字可手动导入，无自动团队云端同步。

参见[部署说明](DEPLOY.md)、[更新记录](CHANGELOG.md)。检查：`node --test tests/core.test.mjs`。技能更新同步：`node scripts/sync-skills.mjs`。
